# AI用語デイリーマスター

AI・ITの基礎用語を毎日3単語ずつ学び、週末に一問一答でおさらいする、スマホ向け学習アプリ（PWA対応予定）。

## 現状（第一段階）

- `index.html` — フロントエンドの画面構造のみ（Tailwind CSS CDN + 最小限のvanilla JS）
  - ヘッダー: アプリタイトル、今日の日付・曜日表示
  - 平日ダッシュボード: 今日の3単語カード（用語／解説／例）＋「覚えた！」トグル
  - 週末ダッシュボード: 一問一答クイズ（タップで裏返るカード）＋「正解」「もう一度」ボタン
  - 下部固定ナビ: 今日の学習／用語集／設定 タブ切替
- バックエンド処理（単語の自動取得・保存・PWA化など）は未実装で、今後の段階で追加予定。

## 動かし方

`index.html` をブラウザで直接開いてください。
